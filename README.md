# WFACT 3.0

Private monorepo for WFACT 3.0: an AI-run web-agency factory and its control room (the Cockpit).

**Agents and engineers start here, in order:**

1. [`CLAUDE.md`](CLAUDE.md) — the law file ("never trust done, only verified") and [`.claude/rules/`](.claude/rules/) — working
   rules for context use, workflow and the quality bar. Non-Claude agents: [`AGENTS.md`](AGENTS.md).
2. [`docs/HANDOFF.md`](docs/HANDOFF.md) — goals, verified state, architecture, backlog, setup.
3. [`PROGRESS.md`](PROGRESS.md) — live status and "Next up"; [`BLOCKED-ON-NICK.md`](BLOCKED-ON-NICK.md) — what waits on a human.
4. [`docs/INDEX.md`](docs/INDEX.md) — which document governs what; [`docs/archive/MANIFEST.md`](docs/archive/MANIFEST.md) — what is retired.

Layout: [`.claude/ARCHITECTURE_MAP.md`](.claude/ARCHITECTURE_MAP.md). Commands: [`.claude/QUICK_START.md`](.claude/QUICK_START.md).
