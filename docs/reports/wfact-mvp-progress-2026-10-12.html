Part by part

The factory itself

Done

The control room is live and working. From it, a request can be turned into a written plan. You approve or reject the plan, a website gets built in one of two styles, and every result is checked automatically before anyone calls it finished. So far it has only run on practice clients, not a real one.

What's happened

  • Approved team members can sign in, and each client's information stays separate and private.
  • Two build styles exist: a fast, simple multi-page site, and a more polished site with motion.
  • Every build is checked automatically for layout, speed, accessibility and honesty (no made-up reviews or clients) before it goes to a person.
  • Each AI worker can only do what it is explicitly allowed to. Everything it does is recorded, along with what it cost.
  • If a build stops partway, the control room explains why in plain words and lets it carry on from where it stopped.

Found and fixed

  • One test build stopped because a connection to the building tool dropped. It now retries automatically.
  • The checker was wrongly marking a site as broken for having no customer reviews when none had been provided. That is fixed, and it no longer pushes for fake reviews.
